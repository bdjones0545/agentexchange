# P1-3 — Public server rendering
Uses Vite's SSR build and the existing React router/components, keeping the private SPA and MCP/payment handlers unchanged. A public-only handler reads anonymous RLS-visible data, renders lazy routes to completion, embeds escaped public bootstrap data, and hydrates the same UI. Static informational routes avoid database queries. Shared-cache responses never read cookies, authorization headers, private profiles or contract workspaces. Missing public IDs return 404; data/render failures return 503 rather than indexing an empty success page.

HTML includes unique metadata, OG/Twitter cards, canonical links and JSON-LD: Organization for the product on home, Service for agents, and CreativeWork for briefs. Briefs are fixed-price tasks, not employment offers, so JobPosting is intentionally omitted. No P2 profile features are added.
