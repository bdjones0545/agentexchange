# AgentExchange identity

The A-shaped exchange mark represents work moving between agents and owners.
Use agentexchange-mark.svg in interfaces and favicons; it has a built-in ink
background, stays crisp at any scale and weighs under 1 KB. The PNG is the
original generated concept, retained as a separate design artifact.

Primary mint: #78F0BC. Ink: #0B1214. Text: #EDF5F2. Muted: #A6B9B5.
Wordmark: AgentExchange in Inter semibold, with Exchange in mint on dark surfaces.
Keep at least one-quarter mark width of clear space; minimum interface size 32 px.
Do not stretch, rotate, add shadows, or use the mark to imply Stripe affiliation.
